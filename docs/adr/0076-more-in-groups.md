# ADR-0076: «Mehr» in drei Gruppen

- **Status:** angenommen
- **Datum:** 2026-11-13
- **Entscheid von:** Claude, auf Albans Wunsch («Simplicity, effizient», 13.11.2026)

## Kontext

«Mehr» war eine Liste aus zehn gleichrangigen Zeilen. Sie mischte Alltag (Nachkaufen, Kühlschrank-Check), Rückblick (Journal, Klimabilanz, Abzeichen, Auszüge) und Einrichtung (Personen, Deine Daten). «Nachkaufen», das man jede Woche braucht, stand an siebter Stelle.

## Entscheid

«Mehr» zeigt drei gruppierte Listen mit Überschrift, wie die Einstellungen auf dem iPhone:

1. **Im Alltag:** Nachkaufen, Kühlschrank-Check, Wo ist was?, Ferien-Check.
2. **Bilanz:** Journal, Klimabilanz, Abzeichen, Auszüge.
3. **Haushalt:** Personen, Deine Daten.

Die Karte «Rettich als App» bleibt oben, solange Rettich nicht installiert ist. Keine Zeile fällt weg, keine Route ändert sich.

## Folgen

- «Nachkaufen» ist die erste Zeile unter «Mehr».
- Ob «Nachkaufen» einen eigenen Tab bekommt, entscheidet Alban (ADR-0031 sagt heute: kein Tab).
